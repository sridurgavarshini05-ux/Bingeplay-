# BingePlay Streaming Analytics Project

## Project Overview
The BingePlay Streaming Analytics Project focuses on analyzing streaming platform data to understand user engagement, viewing behavior, subscription trends, content performance, and customer retention.

Using SQL and Python, this project explores key business questions through data analysis and query-based insights.

## Tools and Technologies
- **MySQL** – Data querying and analysis
- **SQLAlchemy** – Database connectivity
- **Python** – Data analysis
- **Pandas** – Data handling and query result analysis
- **Jupyter Notebook / Google Colab** – Interactive analysis and documentation

## Key Analysis Areas
- Device-wise viewing activity and engagement
- User ratings and content performance
- Binge-watching behavior
- User sign-ups and viewing activity
- Subscription upgrades and overpayment patterns
- Content comeback trends
- Weekly viewing streaks
- Changes in monthly watch time and user engagement

## Project Objective
The objective is to transform streaming data into meaningful insights that can help understand viewer preferences, identify usage patterns, and support data-driven business decisions.

## Project Deliverable
The project is documented in a Jupyter Notebook containing SQL queries, query outputs, and interpretations of the findings.

**Skills Demonstrated:** SQL, MySQL, Python, Pandas, SQLAlchemy, Data Analysis, and Data Interpretation.
